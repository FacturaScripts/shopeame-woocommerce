Este plugin para Wordpress llamado Shopeame es para conectar conectar una tienda online creada con
Woocommerce con el servicio Shopea.me que es el conector intermedio entre tiendas online y el ERP FacturaScripts
(que puedes encontrar en /Users/daniel89fg/Trabajos/FacturaScripts/facturascripts).

Además, este conector hace uso del plugin ShopeameServer (que puedes encontrar en /Users/daniel89fg/Trabajos/FacturaScripts/facturascripts/plugins/ShopeameServer), este plugin es el encargado de recibir los datos de las tiendas online y mandarlos al ERP del cliente.
