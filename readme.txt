Connects your WooCommerce store with shopea.me to sync your orders with your FacturaScripts ERP.

== Description ==

Shopeame connects your WooCommerce store with [shopea.me](https://shopea.me), a service that syncs online stores with the [FacturaScripts](https://facturascripts.com) ERP. Once the store is linked, every new or updated order is sent to shopea.me, which imports it into your ERP.

**Features**

* Adds a **Shopeame** page to the WordPress admin menu.
* Generates read-only WooCommerce REST API keys for shopea.me with one click.
* Two ways to link the store:
  1. Copy the store URL and the API keys and paste them into shopea.me.
  2. Enter the UUID and token of your ERP and the plugin links the store automatically.
* Real-time order sync: new and updated orders are notified to shopea.me as soon as they happen.
* Download the ERP invoices of each order from the orders list and from the order screen, including partial invoices, invoices that group several orders and corrective invoices.
* Customers can download the invoices of their own orders from My account (can be turned off on the Shopeame page).
* Buttons to check the connection, unlink the store or delete the locally saved connection data.
* Compatible with High-Performance Order Storage (HPOS) and the cart and checkout blocks.

**Requirements**

* WooCommerce.
* A shopea.me account with your ERP registered. See the plans on the [pricing page](https://shopea.me/precios).

== Installation ==

1. Install and activate WooCommerce.
2. Install the plugin from **Plugins > Add New** or upload the `shopeame` folder to `/wp-content/plugins/`.
3. Activate the plugin through the **Plugins** menu in WordPress.
4. Go to the **Shopeame** menu and follow one of the two linking options.

== Frequently Asked Questions ==

= Do I need a shopea.me account? =

Yes. The plugin is the connector between your store and shopea.me, so you need to register your ERP on [shopea.me](https://shopea.me) first.

= What permissions do the generated API keys have? =

The keys are created with **read** permission only. shopea.me uses them to download the orders and products of your store. You can revoke them at any time in **WooCommerce > Settings > Advanced > REST API**.

= What happens to my data if I uninstall the plugin? =

When the plugin is deleted from the WordPress admin, it removes its saved options and the WooCommerce API keys it created, so shopea.me can no longer access your store.

= Where can I download the invoices of an order? =

In **WooCommerce > Orders**, click the **Invoices** button of the order, or open the order and look at the **Invoices** box. The plugin asks shopea.me for the invoices that your ERP has for that order every time, so the list is always up to date. Invoices are not stored in WordPress.

= Can my customers download their invoices? =

Yes. In **My account > Orders** each order has an **Invoices** button, and the order page shows an **Invoices** section. Customers only see the invoices of their own orders. You can turn it off on the **Shopeame** page by unchecking **Let customers download the invoices of their orders from My account**.

= Where can I see sync errors? =

Failed notifications are written to the WooCommerce log. Go to **WooCommerce > Status > Logs** and select the `shopeame` source.

== External services ==

This plugin connects to the shopea.me service (https://shopea.me), which is needed to sync your WooCommerce orders with your FacturaScripts ERP. No data is sent until you link the store from the Shopeame admin page.

The following data is sent to `https://shopea.me/WebHooks`:

* **When you link the store using the ERP UUID and token:** the ERP UUID and token you enter, the site URL and the WooCommerce REST API consumer key and secret generated by the plugin.
* **When an order is created or updated (only while the store is linked):** the order ID, the store identifier and the store token. shopea.me then downloads the order details (customer, addresses, products and totals) through the WooCommerce REST API using the read-only keys.
* **When you open the Shopeame admin page while the store is linked, or click "Check connection" or "Unlink store":** the store identifier and the store token.
* **When you or a customer click "Invoices" in the orders list or open an order, in the admin or in My account (only while the store is linked):** the order ID, the store identifier and the store token. shopea.me returns the code, date and total of the ERP invoices of that order.
* **When you or a customer download an invoice:** the order ID, the invoice ID, the store identifier and the store token. shopea.me returns the invoice PDF, which is sent to your browser and is not stored in WordPress.

The plugin also exposes the REST endpoint `/wp-json/shopeame/v1/link`, which shopea.me calls to send back the store credentials after you link the store from shopea.me. Requests are only accepted when they carry a valid HMAC-SHA256 signature made with the consumer secret generated by the plugin.
