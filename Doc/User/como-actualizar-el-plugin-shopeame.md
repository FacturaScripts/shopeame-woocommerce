Cuando se publica una versión nueva del plugin **Shopeame**, WordPress la muestra como la de cualquier otro plugin,
aunque Shopeame no esté en el directorio oficial: no hace falta entrar en GitHub ni volver a subir el zip.

## ⚙️ Antes de empezar

- Entra en el escritorio de WordPress con un usuario que pueda actualizar plugins (un administrador).
- WordPress busca versiones nuevas por su cuenta cada 12 horas. Si se acaba de publicar una, puede tardar en aparecer;
  para buscarla en ese momento, mira el último apartado.

## 🔔 Dónde aparece la versión nueva

Hay tres sitios, y en cualquiera de ellos se actualiza con un clic:

1. **Página Shopeame**: arriba aparece el aviso **Hay una versión nueva de Shopeame: …** con la versión instalada, el
   botón **Actualizar ahora** y el enlace **Novedades**, que abre la página de la versión en GitHub.
2. **Plugins**: bajo la fila de Shopeame aparece **Hay disponible una nueva versión de Shopeame**, con los enlaces
   para ver los detalles de la versión (con sus novedades) y para actualizar ahora.
3. **Escritorio** → **Actualizaciones**: Shopeame aparece en la lista de plugins con actualización. Márcalo y pulsa
   **Actualizar plugins**.

## 🔄 Actualizar

Pulsa **Actualizar ahora** en cualquiera de esos sitios. WordPress descarga la versión nueva, sustituye la anterior y
deja el plugin activo. La tienda sigue vinculada con shopea.me y las claves de la API no cambian.

Al terminar, la página Shopeame muestra al pie **Shopeame versión …** con la versión instalada.

## 🤖 Actualizar automáticamente

En **Plugins**, en la columna **Actualizaciones automáticas** de la fila de Shopeame, pulsa **Activar las
actualizaciones automáticas**. WordPress instalará solo cada versión nueva cuando la encuentre.

Si el enlace no aparece justo después de instalar o actualizar el plugin, vuelve a la lista de **Plugins** pasado un
rato (o tras buscar actualizaciones como se explica abajo): WordPress lo muestra cuando ha comprobado la versión.

## 🔍 Buscar actualizaciones ahora

Al pie de la página Shopeame, pulsa **Buscar actualizaciones**. Se abre **Escritorio** → **Actualizaciones** y
WordPress pregunta en ese momento por las versiones nuevas. Si hay una de Shopeame, aparece en la lista de plugins.
